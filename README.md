# Sofre Desktop 1.0.0

نسخه‌ی ویندوزی برنامه‌ی **Sofre** (اپلیکیشن دسکتاپ مبتنی بر Tauri).

## دانلود

| فایل | نوع | حجم | مناسب برای |
| --- | --- | --- | --- |
| `Sofre_1.0.0_x64-setup.exe` | نصب‌کننده NSIS | ~۱.۹ مگابایت | اکثر کاربران ویندوز |
| `Sofre_1.0.0_x64_en-US.msi` | نصب‌کننده MSI | ~۲.۸ مگابایت | نصب سازمانی / GPO |
| `Sofre-portable-1.0.0-x64.exe` | نسخه پرتابل (بدون نصب) | ~۸.۶ مگابایت | اجرای بدون نصب |

## پیش‌نیازها

- ویندوز ۱۰ یا ۱۱ (۶۴ بیتی)
- WebView2 Runtime (در ویندوز ۱۱ از پیش نصب است؛ در ویندوز ۱۰ معمولاً موجود است، در غیر این صورت از [اینجا](https://developer.microsoft.com/microsoft-edge/webview2/) نصب کنید)

## نصب

1. فایل نصب‌کننده مناسب را دانلود کنید.
2. روی فایل دوبار کلیک کرده و مراحل نصب را دنبال کنید.
3. اگر ویندوز هشدار «Windows protected your PC» نمایش داد، روی **More info → Run anyway** بزنید.

## نسخه پرتابل

فایل `Sofre-portable-1.0.0-x64.exe` را دانلود و مستقیماً اجرا کنید؛ نیازی به نصب ندارد.

## ساخت

این فایل‌ها با `cargo tauri build` در حالت `release` برای معماری `x86_64-pc-windows-msvc` تولید شده‌اند.
